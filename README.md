# 🏰 الهروب من قلعة الدوال

لعبة هروب تعليمية لطالبات ثاني ثانوي لمراجعة درسي **تركيب الدوال** و**العلاقات والدوال العكسية**، مع غرفة مراقبة لحظية للمعلمة.

- رابط الطالبات: `https://اسم-موقعك.onrender.com/`
- لوحة المعلمة: `https://اسم-موقعك.onrender.com/teacher`

---

## خطوات الرفع (مرة واحدة فقط، حوالي 10 دقائق)

### أولًا: رفع الملفات إلى GitHub
1. ادخلي إلى **github.com** وأنشئي حسابًا مجانيًا (أو سجّلي الدخول).
2. اضغطي **+** أعلى الصفحة ← **New repository**.
3. الاسم: `castle-functions` ← اختاري **Public** ← اضغطي **Create repository**.
4. في الصفحة التالية اضغطي الرابط **uploading an existing file**.
5. فكّي ضغط الملف `castle-functions.zip` على جهازك، ثم **اسحبي كل الملفات** إلى صفحة الرفع.
6. اضغطي **Commit changes** في الأسفل.

### ثانيًا: تشغيل اللعبة على Render (مجاني)
1. ادخلي إلى **render.com** ← **Get Started** ← سجّلي بحساب GitHub نفسه.
2. اضغطي **New +** ← **Web Service**.
3. اختاري المستودع `castle-functions` ← **Connect**.
4. اضبطي الإعدادات:
   - **Language / Runtime**: `Node`
   - **Build Command**: `echo ok`
   - **Start Command**: `node server.js`
   - **Instance Type**: `Free`
5. في قسم **Environment Variables** اضغطي **Add Environment Variable**:
   - Key: `TEACHER_PASSWORD`
   - Value: كلمة مرور تختارينها للوحة المعلمة
6. اضغطي **Deploy Web Service** وانتظري حتى تظهر كلمة **Live** (2–4 دقائق).
7. انسخي الرابط الظاهر أعلى الصفحة (ينتهي بـ `onrender.com`). هذا رابط الطالبات، وأضيفي `/teacher` لرابط لوحتك.

> إن لم تضيفي كلمة مرور فالكلمة الافتراضية هي `narjis2026` — يُفضّل تغييرها.

---

## يوم الحصة
1. **قبل الحصة بخمس دقائق** افتحي `/teacher` (الخادم المجاني ينام بعد 15 دقيقة دون استخدام، وأول فتح يستغرق نحو دقيقة).
2. اضغطي **🔗 رابط الطالبات** لعرض الرابط ورمز QR على السبورة.
3. اضغطي **🖥️ وضع السبورة** لعرض الخريطة الحية بملء الشاشة.
4. في نهاية الحصة اضغطي **⬇️ تصدير النتائج** (ملف يفتح في Excel).
5. لفصل جديد: **🧹 جلسة جديدة** (بعد التصدير).

## مهم عن الحفظ في الخطة المجانية
- أثناء الحصة كل شيء يُحفظ في الخادم، ونسخة من تقدم كل طالبة تُحفظ في جهازها أيضًا. إذا أُعيد تشغيل الخادم أثناء اللعب تُستعاد تقدمات الطالبات تلقائيًا عند عودتهن (بعد إعادة تصحيح كل إجابة).
- خوادم Render المجانية **تمسح ملفاتها عند النوم أو إعادة التشغيل**، لذا **صدّري النتائج في نهاية كل حصة**. للحفظ الدائم يمكن إضافة قرص (Disk) مدفوع في Render وضبط `DATA_DIR` على مساره.

## محتوى اللعبة
| الغرفة | اللغز | المهارة |
|---|---|---|
| 🔐 بوابة الشفرات | فتّشي الغرفة عن اللفائف ثم أديري أقراص قفلين | العمليات على الدوال + تركيب الدوال |
| 🪞 قاعة المرايا العكسية | ضعي جواهر المعكوس على الشبكة، ثم ارسمي شعاع f⁻¹ | معكوس العلاقة والانعكاس حول y = x |
| ⚗️ مختبر الخيميائي | اسحبي قوارير الدوال إلى الآلات لصنع h(x) (3 آلات) | تركيب الدوال وتفكيكها |
| 🔮 سرداب الأرواح | اربطي كل دالة بمعكوسها بين ظلال مزيّفة، مع مسبار للتحقق | إيجاد الدالة العكسية والتحقق بالتركيب |
| 💣 خزانة الكنز | قنبلة بمؤقت 6 دقائق: قطع الأسلاك + لوحتا أرقام | اختبار الخط الأفقي، قيم f⁻¹، تركيب مع f⁻¹ |

- لكل طالبة أرقام مختلفة (تُولَّد من بذرة خاصة بها)، والتصحيح يتم في الخادم.
- 3 تلميحات متدرجة لكل لغز (−15 نقطة لكل تلميح) دون كشف الحل، وتغذية راجعة ذكية بعد الخطأ.
- النقاط: 100 لكل لغز − 15 لكل تلميح − 10 لكل خطأ (حد أدنى 30)، +100 عند الهروب، −20 لكل انفجار. 💎 جوهرة لكل لغز يُحل بلا تلميح وبخطأ واحد على الأكثر.
